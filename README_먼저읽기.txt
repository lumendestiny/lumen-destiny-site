루멘 명운 홈페이지 초안입니다.

파일 설명
- index.html: 홈페이지 본문
- styles.css: 색상, 글씨, 화면 배치
- script.js: 연도 자동 표시
- privacy.html: 개인정보처리방침
- terms.html: 이용약관
- support.html: 고객지원

가장 쉬운 무료 게시 방법
1. GitHub 계정을 만듭니다.
2. 새 저장소 이름을 lumen-destiny-site 로 만듭니다.
3. 이 폴더의 파일을 모두 업로드합니다.
4. 저장소 Settings > Pages로 이동합니다.
5. Source에서 Deploy from a branch 선택
6. Branch는 main, 폴더는 /(root) 선택 후 Save
7. 사이트가 열린 뒤 Custom domain에 lumendestiny.com 입력
8. 도메인 구입처에서 GitHub Pages용 DNS를 설정합니다.

주의
- 개인정보처리방침과 이용약관은 앱 기능과 실제 데이터 처리방식 확정 후 반드시 최종 수정해야 합니다.
